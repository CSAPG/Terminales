Dernière étape pour déverrouiller l'Héritage de Newton. Un script Python simule la chute libre sans frottement d'une balle de masse m = 0,15 kg lâchée depuis une hauteur H = 2,0 m (g = 9,8 m·s⁻²).
import numpy as np
m = 0.15
g = 9.8
h = 2.0
v = np.sqrt(2 * g * h)
Ec = 0.5 * m * v**2
print(f"Énergie cinétique finale : {Ec:.1f} J")
