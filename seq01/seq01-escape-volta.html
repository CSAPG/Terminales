⚡ Pièce 4 🔢 Indice calcul 1/3
1 Intensité du courant
Un électrolyseur fonctionne avec un courant d'intensité I = 500 mA pendant Δt = 10 min.

Rappel : q = I × Δt (q en C, I en A, Δt en s)

Convertissez : I = A · Δt = s

Calculez q = C

💡 Le 1er chiffre du code = les centaines de q (ex. si q = 3 00 C → 1er chiffre = 3)
⚡ Pièce 4 🔢 Indice calcul 2/3
2 Quantité d'électrons
q = n(e⁻) × Nₐ × e = n(e⁻) × F avec F = 96 500 C·mol⁻¹

D'après l'indice 1, q = C

Calculez n(e⁻) = q / F = mol

💡 Le 2e chiffre du code = n(e⁻) × 10⁴ arrondi à l'unité (ex. 1,6×10⁻³ → 2e chiffre = 1 car 1,6×10⁻³ × 10⁴ ≈ 16 → dizaine = 1)

📚 Pièce 3 — Archives · Code : 2202
Appariement
e⁻ → anode vers cathode · I → cathode vers anode
K⁺ → vers cathode · NO₃⁻ → vers anode
Vrai/Faux pont salin
✗ Il ne transfère pas les e⁻ (ce sont les ions)
✓ Assure la neutralité électrique
✓ Sans lui, accumulation de charges → arrêt
✗ Il ne mélange pas les solutions
⚡ Pièce 4 — Faraday · Code : 1016
Calcul q = I × Δt
I = 0,500 A · Δt = 600 s
q = 0,500 × 600 = 300 C
n(e⁻) et m(Zn)
n(e⁻) = 300 / 96500 = 3,11 × 10⁻³ mol
n(Zn) = ½ × n(e⁻) = 1,554 × 10⁻³ mol (valeur non arrondie conservée pour le calcul final)
m(Zn) = 1,554×10⁻³ × 65,4 = 0,10166 g = 101,7 mg
Code = 1016 (4 premiers chiffres de m(Zn) en mg)
Pile vs Électrolyseur
Pile : anode ⊖ · réaction spontanée · chimique→électrique
Électrolyseur : anode ⊕ · réaction forcée · électrique→chimique
